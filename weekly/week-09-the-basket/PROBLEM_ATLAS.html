Start with the execution contract

The task is not simply to aggregate scans. The order event feed is live and retains six hours; scan files are copied the next morning and only three nights remain; the price table exposes only its latest nightly snapshot. A correct design must retain history before those source windows expire.

order_events

Event and tip history. Six-hour source retention. Preserve event time and write time separately.

scans

Item-level daily files. Three-night source retention. Keep batch day and load timestamp.

prices

Whole-list nightly snapshot. Latest copy only. Build a historical, effective-dated price view.

CONCEPTUAL DATA FLOW · HISTORY BEFORE BUSINESS LOGIC

Target grain: exactly one row per valid placed order_id, with columns in this order: order_id, status, delivered_at, items, subtotal, tip. The placement window is 2026-10-16 inclusive through 2026-11-14 inclusive (upper bound 2026-11-15 00:00:00 UTC).
