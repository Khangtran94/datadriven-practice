PYTHON · AVIATION WEATHER

You're a data engineer at an airline. Every airport reports its weather about once an hour as a METAR, a short line of code that pilots read. Collectors logged each METAR as 1 JSON line, and the dispatch team needs 1 clean row per report to study the delays around New Year. Write the code that turns the log into that table.

DATA SOURCECollector JSONL envelopes · METAR / SPECI observation reports
1Normalize collector and archive envelopes
2Parse weather groups without positional guesses
3Reconstruct UTC time and deduplicate corrections

The business context and condition descriptions are taken from README.md. No separate Week_10_DOC.md is present in this folder; every source record below is an illustrative teaching fixture based on the README and the inspected Python/reference files, not a hidden-dataset record.
